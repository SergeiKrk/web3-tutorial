# AGENTS.md — web3Crypto

## Domain
Изучение web3-разработки и создание крипто-пет-проекта. Охват: блокчейн-основы, смарт-контракты (Solidity), dApps (React + ethers.js/wagmi), DeFi, NFT, безопасность, инфраструктура. Цель: понимание технологии на уровне «могу спроектировать и реализовать dApp».

## Language
- Все записи на русском
- Технические термины — на языке оригинала с русским пояснением
- YAML frontmatter: ключи на английском, значения на русском

## Structure
```
web3Crypto/
├── AGENTS.md        ← Этот файл
├── raw/             ← Исходные материалы (статьи, доки, примеры кода)
├── wiki/            ← Обработанные страницы
├── index.md         ← Каталог wiki-страниц
└── log.md           ← Хронология операций
```

## Conventions
- Wiki-ссылки: `[[wiki/PageName]]`
- Категории: `concept` (концепция), `tool` (инструмент/библиотека), `analysis` (сравнительный анализ), `tutorial` (гайд), `project` (пет-проект), `meta`
- YAML frontmatter: `title`, `date`, `tags`, `category`, `source_count`
- **Уроки оформляются как одиночные файлы** с naming convention `0_lesson-XX-описание.md`
- Flashcards, interview questions и практические задания добавляются как разделы внутри основного файла урока, а не как отдельные документы

## Workflows
1. **Изучение темы**: поиск источников → raw/ → обсуждение → wiki/
2. **Практика**: создание кода → сохранение в raw/ (сниппеты) → wiki/ (разбор)
3. **Проектирование**: выбор пет-проекта → архитектура → итерации
4. **Линт**: проверка перекрёстных ссылок и сиротских страниц
